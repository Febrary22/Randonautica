# 일탈 (Escapade)

란더노티카(Randonautica)에서 영감을 받은, 과학적 필터링 기반의 미스터리·모험 위치 탐험 앱.

지금까지 정리된 게임 기획(지도 선택, 안전 필터링 알고리즘, 밀도 분석, 백그라운드 걸음수 추적,
수익모델, GPS 안티치트, 다국어 등)은 [게임 기획 문서](docs/GAME_DESIGN.md)를 참고하세요.

이 저장소에는 그 기획의 **핵심 루프만 뽑아낸 웹 프로토타입**이 들어있습니다 — 실제 배포용 앱이
아니라, 좌표 생성 → 접근 비프음 → 도착 → 결과 화면 흐름이 실제로 동작하는지 빠르게 확인하기
위한 것입니다. 무엇이 단순화됐는지는 아래 "프로토타입의 한계" 섹션과 소스 코드 곳곳의
`SIMPLIFIED` 주석을 참고하세요.

## 실행 방법

```bash
npm install
npm start          # http://localhost:3000
```

컴퓨터의 브라우저에서 `http://localhost:3000`을 열면 위치 권한 요청부터 바로 테스트할 수
있습니다(로컬호스트는 보안 컨텍스트로 취급되어 위치 API가 동작합니다).

**실제로 걸어보면서 휴대폰으로 테스트하려면**, 브라우저 대부분이 위치 API에 HTTPS(보안 컨텍스트)를
요구하므로 터널링이 필요합니다:

```bash
npx localtunnel --port 3000     # 또는: ngrok http 3000
```

터널이 알려주는 HTTPS 주소를 휴대폰 브라우저로 열면 됩니다. 같은 와이파이가 아니어도(터널이므로)
동작합니다.

## 휴대폰에 "설치"하기 (PWA)

이 프로토타입은 홈 화면에 추가할 수 있는 PWA(manifest + service worker + 아이콘)로 만들어져
있습니다. 앱스토어 없이도 아이콘을 눌러 실행하는 "설치된 앱"처럼 쓸 수 있습니다.

1. 위의 방법(로컬 실행 + 터널, 또는 아래 "배포하기")으로 얻은 **HTTPS 주소**를 휴대폰
   브라우저로 엽니다.
2. **iPhone(Safari)**: 공유 버튼 → "홈 화면에 추가". **Android(Chrome)**: 메뉴(⋮) →
   "앱 설치" 또는 "홈 화면에 추가" (하단에 설치 배너가 자동으로 뜨기도 합니다).
3. 홈 화면에 생긴 아이콘으로 실행하면 주소창 없이 전체화면 앱처럼 열립니다.

주의: 위치 권한(§geolocation)은 HTTPS(또는 컴퓨터에서 열 때의 localhost)에서만 동작합니다.
`http://`로 시작하는 사설 IP 주소로는 설치는 되어도 위치 기능이 막힙니다.

### 배포하기 (매번 터널을 새로 열지 않으려면)

이 저장소를 만든 세션은 원격 샌드박스라 제 쪽에서 바로 공개 URL을 드릴 수는 없습니다.
대신 GitHub에 올라간 이 저장소를 아래처럼 무료 호스팅에 연결하면 고정된 HTTPS 주소가
생깁니다(다음에 계속 이 URL로 접속 가능):

- **Render** (render.com): New → Web Service → 이 GitHub 저장소 선택 → Build Command
  `npm install`, Start Command `npm start` → 배포 후 나오는 `https://<앱이름>.onrender.com`
  주소를 휴대폰에서 열면 됩니다. (무료 플랜은 한동안 요청이 없으면 잠들었다가 첫 요청 시
  10~30초 정도 깨어나는 지연이 있을 수 있어요.)
- **Railway**, **Fly.io** 등 Node 앱을 지원하는 다른 PaaS도 동일한 방식으로 가능합니다.

원하시면 다음 단계로 같이 배포 설정 파일(예: `render.yaml`)을 추가해드릴 수 있습니다.

## 테스트

```bash
npm test
```

네트워크 호출이 필요 없는 순수 로직(좌표 수학, 제외 구역 판정, 밀도 분류, 위험도 스코어)에
대한 단위 테스트입니다. Overpass/OSRM처럼 외부 API를 호출하는 부분은 이 저장소를 만든
빌드 환경의 네트워크 정책상 실제 호출을 검증하지 못했습니다 — 코드 리뷰로만 확인했으니,
처음 실행할 때 한 번은 스모크 테스트로 봐주세요.

## 무엇이 들어있고, 무엇이 빠졌나

`docs/GAME_DESIGN.md`에서 설계한 것 중 이 프로토타입이 구현한 것:

- §2 좌표 생성 파이프라인 — 몬테카를로 샘플링 + OSM 기반 수역/주요도로 배제 + POI 밀도 기반
  attractor/void/anomaly 간이 분류 + OSRM 기반 도달 가능성 확인(모두 best-effort, 외부
  API가 막히면 경고와 함께 우아하게 성능 저하)
- §2.4 위험도 스코어 — 야간·저배터리·고립도만 반영한 간이 버전(조명·날씨·통신음영 등은 미구현)
- §4 거리 기반 비프음 — 지수 감쇠 간격 공식 그대로, 무음/진동 모드 포함
- §7 결과 화면 — 걸음수(GPS 경로 기반 추정치)·시간·경로 지도·별점/후기·공유 시 포인트 1.5배

**이 프로토타입에 없는 것** (프로덕션 전 반드시 채워야 할 부분, `docs/GAME_DESIGN.md` 참고):

- §3 네이티브 백그라운드 걸음수/헬스킷 연동 (브라우저는 실제 만보계에 접근 불가 — 지금은 GPS
  이동거리 기반 추정치)
- §5 로어/현지 괴담 시스템, §6.1 유물 체계, §8 구독·광고, §9 GPS 안티치트, §12 다국어
- §2.2의 건물/공사장/사유지 배제 레이어(수역·주요도로만 구현), §2.3 KDE/LOF(간이 POI
  밀도 휴리스틱으로 대체)

## 프로젝트 구조

```
src/                    백엔드 (Express)
  geo.js                순수 좌표 수학 (테스트 있음, 네트워크 호출 없음)
  overpass.js           OSM Overpass/OSRM 호출 (수역·도로 배제, 도달 가능성 확인)
  coordinateGenerator.js §2 파이프라인 오케스트레이션
  riskScore.js          §2.4 간이 위험도 스코어
  server.js             API 서버 + 정적 파일 서빙
public/                 프론트엔드 (프레임워크 없는 순수 HTML/CSS/JS)
  index.html, style.css, app.js
test/                   단위 테스트 (node:test)
docs/GAME_DESIGN.md     전체 기획 문서
```
